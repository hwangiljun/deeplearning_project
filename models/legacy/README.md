# 초기 버전 산출물 (기록용)

현재 코드와 **호환되지 않는다**. 아래 차이 때문에 로드해도 동작하지 않는다.

| | 초기 체크포인트 | 현재 |
|---|---|---|
| 출력 클래스 | 11개 (`strikeout`/`walk` 포함) | 10개 |
| 시퀀스 피처 | 12개 (카운트가 섞여 있음) | 8개 (물리량만) |
| 맥락 피처 | 원시 정수 6개 | 15개 |
| 시퀀스 길이 | 8 (타자별, 시간 역순) | 6 (타석 내, 시간순) |

`paper_model.pth` 는 미래 정보 누수가 있는 데이터로 학습되었다.
자세한 내용은 저장소 루트의 README 를 참조.

노트북 원본은 `notebooks/baseball_model.ipynb` 에 보존되어 있다.
